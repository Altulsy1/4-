🍎 Fruit Clash - لعبة الفواكه الأربعة 🍌
=============================================

نسخة مطورة ومحسنة بالكامل - جاهزة للتشغيل الفوري!

🚀 المميزات:
-----------
• تصميم عصري وجذاب يدعم اللغة العربية بالكامل
• وضع اللعب الجماعي (حتى 4 لاعبين)
• إنشاء غرف خاصة ومشاركتها عبر QR code أو رابط
• نظام إحصائيات متكامل
• تأثيرات بصرية (Confetti) واهتزاز (Haptic)
• دعم كامل للجوال والأجهزة اللوحية
• واجهة مستخدم سلسة وسريعة الاستجابة
• أزرار تفاعلية مع تأثيرات حركية

📁 هيكل الملفات:
---------------
game-modern.js     # ملف اللعبة الرئيسي (محسن بالكامل)
style-modern.css   # ملف التصميم والتنسيقات (محدث)
index.html         # الصفحة الرئيسية (محسنة)
manifest.json      # ملف تعريف تطبيق الويب
README.txt         # هذا الملف
server.js          # خادم WebSocket (اختياري)

🛠️ متطلبات التشغيل:
-------------------
• أي متصفح حديث (Chrome, Firefox, Safari, Edge)
• اتصال إنترنت لتحميل الخطوط والمكتبات
• (اختياري) Node.js لتشغيل server.js للتطوير المتقدم

🚀 كيفية التشغيل:
----------------
1. الطريقة الأسهل - افتح الملف مباشرة:
   • افتح ملف index.html في أي متصفح حديث
   • كل شيء سيعمل مباشرة بدون إعدادات!

2. للتطوير مع خادم محلي:
   • تأكد من تثبيت Node.js
   • شغل الأمر: node server.js
   • افتح المتصفح على http://localhost:8080

3. للتجربة على جوال:
   • شغّل اللعبة على جهازك
   • افتح الرابط على الجوال
   • أو امسح رمز QR من شاشة الغرفة

🎮 طريقة اللعب:
--------------
1. قم بتعديل اسمك بالضغط على زر التعديل
2. اختر "إنشاء غرفة جديدة" أو "انضم إلى غرفة"
3. انتظر انضمام لاعبين آخرين (يحتاج 2 على الأقل)
4. ابدأ اللعبة - كل لاعب يحصل على 4 بطاقات
5. حاول جمع 4 بطاقات متطابقة من نفس الفاكهة
6. اضغط "لقد جمعت 4!" للفوز بالجولة
7. استمر في اللعب لتحطيم أرقامك القياسية!

🔧 التخصيص والإعدادات:
---------------------
